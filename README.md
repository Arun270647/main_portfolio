
# Arun Vignesh Portfolio

A modern, responsive portfolio website for Arun Vignesh, Full Stack Developer. Showcasing projects, certificates, tech stack, and more.

## 🚀 Features
- Hero section with animated typing and social links
- Projects section with live demo links and custom images
- Certificates and experience stats
- Responsive tech stack grid with SVG icons
- Downloadable resume
- Modern UI/UX with Tailwind CSS and AOS animations
- Fully static, no database dependencies

## 🛠️ Tech Stack
- React.js (Vite)
- Tailwind CSS
- Material UI
- Lucide React Icons
- AOS (Animate On Scroll)
- SVG icons for tech stack

## 📁 Project Structure
```
├── src/
│   ├── assets/           # Images, SVGs, resume
│   ├── components/       # Reusable React components
│   ├── Pages/            # Main page components (Home, About, Portfolio, etc.)
│   └── main.jsx          # App entry point
├── public/               # Static files
├── index.html            # Main HTML file (favicon, meta tags)
├── package.json          # Project dependencies
```

## 🖥️ Local Development
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Arun270647/your-portfolio-repo.git
   cd your-portfolio-repo
   ```
2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```
4. **Open in your browser:**
   Visit [http://localhost:5173](http://localhost:5173) (or the port shown in your terminal).

## 🌐 Deployment
- **Netlify:**
  - Connect your GitHub repo to Netlify.
  - Set build command: `npm run build`
  - Set publish directory: `dist`
- **Vercel, GitHub Pages, etc.** also supported.

## 📄 Customization
- Update your profile image in `src/assets/hero_image.jpg`.
- Add or update project images in `src/assets/projects/`.
- Edit your resume at `src/assets/Arun Resume.pdf`.
- Update social links and content in `src/Pages/Home.jsx` and `src/Pages/About.jsx`.
