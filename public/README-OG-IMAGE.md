# Generate OG Image

The OG image should be **1200x630 pixels** for optimal social media sharing.

## Quick Generation Options:

### Option 1: Use the HTML Generator (Recommended)
1. Open `scripts/generate-og-image.html` in your browser
2. It will auto-download `og-image.png`
3. Move the file to `public/og-image.png`

### Option 2: Use an Online Tool
1. Go to https://www.canva.com/create/og-images/
2. Create a 1200x630px image with:
   - Background: #0a0a0a (black)
   - Text: "ARUN VIGNESH" in green (#00ff41)
   - Subtitle: "Full-Stack Web Developer"
   - Tech: React • TypeScript • Node.js
3. Download as PNG and save to `public/og-image.png`

### Option 3: Use the SVG
The file `public/og-image.svg` has been created and can be used directly.
Update the meta tags to use `.svg` instead of `.png` (most platforms support SVG).
